# Loan-Request-Form-React-
A simple React project that implements a "Requesting a Loan" form, demonstrating form handling and validation using React Hooks.

# => Features
- Single useState object to manage all form fields (controlled inputs): name, phone number, age, employment status, and salary.
- Validation for phone number and age triggered on Submit.
- Conditional popup overlay showing success, invalid phone, or invalid age messages based on validation results.
- Submit button visually activates (via an active class) only once all fields are filled.

# => Tech Stack
- React (Functional Components + Hooks)
- Plain CSS (custom styling)
